# Brainstorm-Enhanced
![Brainstorm-mod logo](Assets/BrainstormLogo.jpg)

Brainstorm-Enhanced is a fork of Brainstorm focused on quality-of-life improvements for Balatro.

## Credits
- Upstream project: [OceanRamen/Brainstorm](https://github.com/OceanRamen/Brainstorm)

## Requirements
- [Lovely Injector](https://github.com/ethangreen-dev/lovely-injector/releases)

## Installation
1. Install Lovely and follow its manual installation instructions.
2. Place this mod in your Balatro mods directory.
3. Ensure the mod folder name is `Brainstorm`.
4. Reload the game.

Windows mods path:
- `%appdata%/balatro/mods`

macOS mods path:
- `/Users/$USER/Library/Application Support/Balatro/Mods`

## Default Keybinds
- Save state to slot 1-5: hold `Z` and press `1-5` (or hold `1-5` then press `Z`)
- Load state from slot 1-5: hold `X` and press `1-5` (or hold `1-5` then press `X`)
- Fast reroll: `Ctrl + T`
- Toggle auto-reroll: `Ctrl + A`
- Stop active auto-reroll search: `Ctrl + P`

## Features
- Save states
- Fast reroll
- Auto-reroll with configurable filters
- Extended game speed options
